# patrick12138.github.io

[English](./README.md) | [简体中文](./README.zh-CN.md)

Small static pages I actually use, hosted on GitHub Pages. No framework, no backend — posts and the index are generated locally by `tools/` and pushed; Pages just serves the result.

## Pages

| Path | What it is |
| --- | --- |
| `/` | Blog index — original posts and reposts, newest first |
| `/posts/<slug>/` | Individual posts |
| `/lab/` | Lab — small things I build for myself |
| `/backlog/` | Games backlog — tick off what I finish, watch the hours drop |
| `/tga/` | The Game Awards GOTY nominee checklist, 2014–2025 (68 entries) |
| `/about/` | Terminal-style personal page, English / 中文 toggle |

## Structure

```text
index.html          Blog index (generated by tools/gen_index.py)
posts/*/index.html  Posts (generated by tools/md2post.py, share assets/base.css + post.css)
lab/index.html      Lab index
tga/index.html      TGA checklist (tool page, inline styles)
about/index.html    About page (tool page, inline styles)
assets/*.css|site.js Shared shell + article styles, theme / back-to-top script
assets/posts/*/     Images downloaded from original posts
tools/              Build scripts (md → post, index, TOC, word count, QA)
.nojekyll           Serve files as-is, skip Jekyll
```

## Adding a page

- **Posts**: don't hand-write HTML. Use `tools/md2post.py`, then `tools/build.py --push` (it regenerates the index).
- **Tool pages**: create `<slug>/index.html` with CSS, JS and data inline so it runs as a single file; the index listing is generated, not hand-edited.

## Notes

- Every page stores its state in `localStorage`. Nothing is uploaded anywhere.
- `/` and `/tga/` load no external fonts or CDN. `/about/` pulls Figtree and JetBrains Mono from Google Fonts and falls back to system fonts if that fails.

## Development

Everything is generated from `tools/` — no hand-edited HTML.

| Script | Purpose |
| --- | --- |
| `build.py` | One command: rebuild → TOC → index → asset hashes → QA → optional push |
| `md2post.py` | Markdown → one post page (localises images, turns media into links) |
| `rebuild.py` | Rebuild every post from `sources.json` |
| `add_toc.py` | Inject / refresh table of contents (idempotent) |
| `gen_index.py` | Regenerate the home list by scanning `posts/` (word counts included) |
| `stats.py` | Add "characters · estimated reading time" to each post |
| `qa.py` | Typography check — any P0 blocks deploy |
| `test_pipeline.py` | Regression tests: idempotency of md2post / add_toc / gen_index |

`post_template.html` is the article shell; `sources.json` maps slug → vault source (`md2post.py` writes it automatically).

```bash
python3 tools/build.py --push "feat: new post"
```

Asset versions (`?v=`) are content hashes written by `build.py`; never edit them by hand.
