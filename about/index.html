01

MusicBridge

A few music players. One window. One set of controls.

A Windows desktop app built with .NET 8 and WPF. It embeds supported player windows into a single host and puts playback, pause and track switching on one set of controls, so you stop hunting for the right window every time a song ends.

Started because I kept three players open at once, all day.

02

CrossPlatformAutoFetcher

Three music charts, one CSV.

A small Windows tool in Python that pulls chart data from QQ Music, NetEase Cloud Music and Kugou, then exports it straight to CSV — replacing half an hour of copy, paste and reconciliation every time the charts moved.

github.com/patrick12138/CrossPlatformAutoFetcher → Windows
03

KaraokeLyricsControl

Word-by-word karaoke lyrics, as a WPF control.

Supports both KRC and KSC lyric formats, drives the highlight from a per-word timeline, and leaves rendering open so the host app can style it. Shipped as a .NET 6 control library — add the reference and it works.

github.com/patrick12138/KaraokeLyricsControl →
04

nodejs_crawl

Car prices from three sites, on a schedule.

Node.js scrapers that collect model and trim prices from Autohome, Dongchedi and Bitauto, normalise them into one shape, and keep a running history so price moves are visible instead of anecdotal.
