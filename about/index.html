01

TGA 年度游戏清单

68 席提名，勾出玩过的，算出还要玩多少小时。

2014–2025 十二届「年度游戏」的全部提名，每一席都能标成通关、玩过没通、 想玩、不打算玩，或者平台够不着。时长取自 HowLongToBeat 的全收集数据， 按「每天 3 小时」换算成还要多少天。

只有 PS 和 Switch 独占的那 14 席默认标成没得玩， 所以进度算的是能玩的 54 席。

patrick12138.github.io/tga/ → Web
02

MusicBridge

几个音乐播放器，一个窗口，一套控制。

.NET 8 + WPF 写的桌面程序。把支持的播放器窗口嵌进同一个宿主界面里， 播放、暂停、切歌走统一的控制，不用来回来去切窗口。

起因是常年同时开着三个播放器，每次切歌都要先找窗口在哪。

github.com/patrick12138/MusicBridge → Windows
03

CrossPlatformAutoFetcher

三个平台的音乐榜单，一键抓成 CSV。

Python 写的 Windows 桌面工具，抓 QQ 音乐、网易云、酷狗的榜单数据， 直接导出 CSV。省掉每次手工复制粘贴再对账的那半小时。

github.com/patrick12138/CrossPlatformAutoFetcher → Windows
04

KaraokeLyricsControl

WPF 的卡拉 OK 歌词控件，逐字高亮。

支持 KRC 和 KSC 两种歌词格式，按字切时间轴做高亮，渲染方式可以自己定制。 做成 .NET 6 的控件库，其他 WPF 项目直接引用就能用。
