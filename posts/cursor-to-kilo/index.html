从 cursor 到 kilo + api

写给对 AI 有点兴趣、但不需要写代码的人看。不保证客观，全是我自己这几年的取舍。

从 cursor 到 kilo + api，claude code、codex、ChatGPT 桌面端，这几年我电脑上的常用软件基本被这批东西轮流占着。

往回捋一遍大概是这么个脉络：23 年是 prompt 工程，24 年是 context，25 年是 agent 和 mcp，26 年开头统一到了 agent skills。说得好听是能力升级，实际上 skills 也就是一些脚本加一些 prompt 的合集吧，本质还是一种“AI 的统一能力”，依旧在烧 token。只是模型和应用的能力越来越好了，未来是可期的。

24 年：我基本没上车

24 年前半年 cursor 我压根没用，后半年也没怎么关注 IDE 这块的发展。现在回头看，那时候模型能力确实还差点火候，就算上车体验也一般。所以这一年对我来说更像是在旁边看着，没什么值得写的实战。

25 年：agent 真正开始有意思

25 年算是分水岭。Google 那边学生会员能白嫖 Gemini，我用了挺久；cc（claude code）则是靠 Any 统筹着用了一整年。年中往后 codex 开始发力，skill 这个形态推出来之后，各家才开始往通用化走。

不过我自己真正开始“炼化” skill 是 26 年的事。25 年更多是在用别人做好的东西。

26 年：harness 百花齐放，模型感觉撞墙了

26 年的变化不在模型，在 harness。模型能力我自己感觉是遇到瓶颈了，涨得没那么猛；但 deepseek 把成本打下来了，能力维持在中上水平，配上好一点的 harness，就能用很便宜的 api 把所有平台都用 agent 管起来。这一年真正的杠杆在这儿。

我试过或者一直在用的，大概是这些：

移动端有 openminis，本地 harness 做得不错，出门在外能用。coding 这边 pi 和 omp 是我认为最好的两个 harness。订阅制里 cc 和 codex 依旧是领先的。

ade（agent development environment）这一年多得像雨后春笋：paseo、orca、multica 都在冒头。我自己常用 herdr 这个多 agent terminal，omp 作者新出的 tern 也会去试。kero 是低空飞行老师的新 ade，界面挺好看。tern 跟 omp 是深度集成的，好用，就是资源占用有点高。

harness 具体我怎么配：日常代码是 cc cli 和 vsc 插件；codex 包括 win 桌面端，偶尔会卡，也许 macOS 上会好一些；Hermes 我用得不多，desktop 有点卡，启动也慢；opencode 开箱即用是真的舒服，但依旧得挂 tun 模式才能用。

omp 我高强度用了两个月，配 dsv4pro 是能打的。pi 是 10 月正式版出来的，配 flash1017 感觉比 dsh 好用。所以现在主力是 omp 当第三方 coding agent，pi 补位。

订阅这块我没订。我的判断是：订阅只对应厂商自己的 harness 才划算，跨着用就没意义了。web 端 deepseek 出的 harness 我没玩，dsh 后来出了 desktop 版本，还行。

顺带说一句工具链上的小东西：ds 现在官方 api 的速度跟质量都还不错，关键是能全平台接进各种 harness；magpie 这种聚合工具比 ccs 好用很多，这一点体感很明显。

1017 那轮横评

各家 harness 里 flash1017 的表现有人做过评测，我自己用下来的感受跟结论差不多：pi 确实更快一点，思考链也更长。它的 token 速度挺快，完成任务也还好，主打就是便宜量大。

最后

这几年我的体会是，别把精力全花在追新工具上。模型能力会自己往前走，harness 会自己卷，真正沉淀下来的是你对“这件事该怎么做”的判断。工具换了三轮，判断力没换。

未来是可期的。
