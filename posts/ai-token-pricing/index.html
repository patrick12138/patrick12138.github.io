一句话结论

2026 年 10 月，Claude 每 1 美元月费换到的 API 用量是 Codex 的 2–4 倍；官方倍率（5x / 20x）与实测基本对不上，Max 20x 只比 Max 5x 多 30–100%，价格却是 2 倍。Copilot 不属于同一赛道，它是按 API 价约 1.0–1.8 折转售。

三个反直觉事实：

  1. 「20x」是 5 小时窗口的倍率，不是周额度的。实测 Max 20x 的 5 小时窗口约是 Pro 的 15×，但周额度只有 Pro 的 9.7×。周额度才是长期天花板。
  2. 20x 相对 5x 只有 1.5–2.2×（社区倍数表），另一组 CC Switch 记录是 $1,100 → $1,500（+36%）。两倍价格换不到两倍额度。
  3. Codex 侧实测离散度约 2 倍，因为 OpenAI 的额度表就是按 API 美元标价的（1 credit = $0.04 API 价值，与公开价严格一一对应），模型构成一变，美元数就跟着变。所以 Codex 只有 credits 是稳定口径。

五、口径陷阱（比数字本身更重要）

  1. 缓存命中率是最大变量。Claude 订阅里缓存读取几乎不占额度，Codex 里缓存读取按 1/10 价照扣。同一份额度，缓存命中高的人能跑出几倍的 token 总数。所以比套餐看「非缓存 token」或「API 等价美元」，不要看 token 总数。
  2. 输出占比。写代码输出约占 5%，写文档能到 30%，而输出是输入的 5 倍价——同样的钱，能买的 token 直接腰斩。
  3. 推理档位比模型选择更费。同一个 Astra，high 和 min 的额度消耗差 3–5 倍，但 token 数只差 2 倍（思考 token 按输出价计费）。
  4. 长上下文翻倍。多数模型有 >272K 的 long context 档，价格 ×2。Copilot 官方文档自己建议默认别切大窗口。
  5. 厂商在做 A/B 灰测。SemiAnalysis 发现 3 个同款账号里 1 个额度低约 20%，厂商承认是「extremely tiny」的测试。任何单账号实测都可能是被灰测的那一个。
  6. 窗口结构不同。Claude 是「5 小时 + 周」双层，Codex Pro 只有周额度（可以一次性打光），Copilot 是纯按量。同样「用满」，节奏完全不同。
  7. 官方倍率 ≠ 实测倍率。Anthropic 只公布 5 小时窗口倍率，OpenAI 已经不再公布任何相对倍率。

六、判断

  • $100 的 Claude Max 5x 是全场最优买入点（44–54×）。Pro 和 20x 都只有 36–37×。20x 的 $100 溢价买的是峰值爆发能力，不是总量。
  • Claude Pro $20 是性价比之王：一年 $240 换约 $8,900 的 API 用量，一个月 7.8 亿 Opus token，够一个人全职 vibe coding。
  • OpenAI 的订阅已不值得当「额度池」买。9/29 之后官方自己说要让订阅价值与 API 价值收敛，翻译过来就是补贴退坡。Codex 现在值钱的是 Ultrafast（$500 档，额度按 8× 扣）和 GPT-6.1 Sol（$2/$10，与 Sonnet 5.5 同价），不是额度。
  • Copilot 是另一套东西：按 API 价约 1.0–1.8 折转售，20 多个模型任选、IDE 深度集成。它值钱在「一个订阅通吃」和合规，不在额度。纯比额度效率，它是几个选项里最差的。
  • Codex Plus 用 Astra 一个月只有 1.2 亿 token，agent 场景两三天就没了——OpenAI 这么定价就是在逼你用 Sol。
