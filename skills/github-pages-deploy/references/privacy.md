# 上线前脱敏

站点是 public 的。**个人可识别信息不能出现在页面上**——包括搬运文章里别人写的、你转述的。

## 三类红线

| 级别 | 内容 | 例子 |
|---|---|---|
| **P0 绝不出现** | 前公司/客户名、证件类、手机号、内网地址、密钥 | 合地、保信、华钦、CLPS、富卫、身份证、192.168.x.x、ghp_/sk- 开头的串 |
| **P1 建议处理** | 求职痕迹、薪资数字、公开邮箱（搬运原文的可以保留，自述的要删） | 求职、内推、面试话术、月薪 3 万 |
| 可保留 | 公开署名、原文作者邮箱、通用技术词 | Eric S. Raymond 的 esr@thyrsus.com（原文自带） |

## 怎么改

1. **前公司名 → 代号**：`Work/合地/` → `Work/公司A/`，叙述里也一起换（"整理合地项目的业务地图" → "整理公司A项目…"）。
2. **求职语境 → 中性**：`对个人求职的用法` → `对个人职业发展的用法`；`面试话术` → `沟通素材`；`最近求职准备` → `职业准备`。
3. **删掉比替换更安全**：拿不准的那句话，直接删，别保留半句。
4. **改源文件**：md 在 vault 里，改完重新 `md2post` 生成页面，**不要只改 HTML**（下次 rebuild 会冲回来）。

## 自动化

`qa.py` 里 `check_privacy()` 每次构建都会扫：

- P0：前公司名 / 证件 / 手机号 / 内网地址 / 疑似密钥 → 直接阻止上线
- P1：求职痕迹、薪资、邮箱 → 提示人工确认

匹配范围是**正文可见文本**（去掉标签后），所以代码块里的密钥也会被抓到。
